# WatchFlix

Your films and TV shows, on your own PC, like a streaming service. Windows 10/11, 64-bit.

**[Download](../../releases/latest)** · Setup.exe or portable zip

## Features

- Reads your existing folders; nothing moved or renamed
- Films and TV shows
- Plays every file as it is (MKV, HEVC, 10-bit, DTS)
- Audio and subtitle tracks
- Continue watching
- Details from TMDB, TVmaze and OMDb
- Actor pages
- Pop-out player
- Hover previews
- Updates itself
